# Table for Two

Shared weekly meal plan for Jevon and Jaiden. Week 3 (Mon 9 – Sun 15 Nov 2026) is live: Daryl's macros, prepped meals, a small bank Mon–Thu for Friday and Saturday, and fibre, fullness and water as the week's focus.

- `index.html` is the dashboard (single page, no build step). Open it in a browser or serve the folder.
- `recipes.json` is the recipe database (203 recipes). The same data is embedded in `index.html`.
- `img/` holds 81 recipe photos used by the recipes that reference `img/pbNN.jpg`.

## Notes

- This repo is a snapshot of the hosted claude.ai artifact. Shared ticks and swaps are stored in that artifact's database, not here. Opened outside claude.ai, they save on the device only and the Ask assistant is unavailable.
- 108 recipes use photos that were embedded in the hosted page (`att:`, `wm:`, `alf:` keys) and could not be exported, so they show as colour tiles here.
